# PUJO — a digital Durga Pujo pandal

An interactive, ambient, nostalgic website: one Bengali Durga Pujo night, told through the props of a 90s–early-2000s Kolkata childhood.
Inspired by saloon.wtf (atmosphere) and schoolkebaad.fun (clean, prop-based UI).
Built for Pujo 2026 and every Pujo after it, one **edition** per year.
